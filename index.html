Perguntas frequentes

        

          

            Onde ficam salvos os meus dados?
            
Todos os dados (clientes, registros, agenda, avisos) ficam salvos apenas neste navegador, neste computador. Nada é enviado para um servidor externo.

          

          

            Como faço backup dos meus dados?
            
No menu, em "Dados", use "Exportar backup" para baixar um arquivo com tudo, e "Importar backup" para restaurar em outro navegador ou aparelho.

          

          

            Como altero meu usuário e senha?
            
Na tela de login, use o link "Esqueci minha senha" para apagar o acesso salvo neste navegador e cadastrar um novo.

          

          

            Como personalizo a imagem de cada página?
            
Administradores veem o botão "Add imagem" no canto superior direito do banner de cada página, para enviar uma imagem de fundo própria.
